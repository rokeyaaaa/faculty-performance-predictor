# Faculty Performance Predictor using Video Analytics

## Project Description
This project predicts faculty performance using classroom video analytics and machine learning.

Traditional faculty evaluation methods rely on student feedback forms which can be biased.  
This system uses computer vision and machine learning to analyze classroom videos and predict faculty performance.

## Features
- Video analysis using OpenCV
- Student engagement detection
- Faculty interaction analysis
- Machine learning based performance prediction
- Web interface for predictions

## Technologies Used
Python  
OpenCV  
Scikit-learn  
Flask  
HTML CSS JavaScript  

## Project Structure
faculty-performance-predictor

backend – Flask API for prediction  
frontend – Web interface
